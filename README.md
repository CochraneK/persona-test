# Persona Test · 人格投射测验

一组轻量、可玩、可分享的人格投射测验，纯静态 HTML（无后端、无埋点），适合做社交传播与破冰引流。

## 包含的测验

| 文件 | 说明 |
| --- | --- |
| [`persona-image.html`](persona-image.html) | **旗舰版**：12 个测验单页聚合（音频 / 选椅子 / 动物 / 猫 / 狗 / 食物 / 色彩 / 气球 / 抛球 / 天气 / 城市 / 花），含图片资源 `img/`。 |
| [`persona-collection.html`](persona-collection.html) | **视觉投射合集（A–F）**：纯 emoji 与 SVG，零外部资源，离线可用。 |
| [`chair-test.html`](chair-test.html) | **会议室选椅子**：经典空间投射测验，4 场景 SVG + 9 型五维画像。 |

在线访问：[https://cochranek.github.io/persona-test/](https://cochranek.github.io/persona-test/)

## 玩法与设计

- **单 pick 视觉投射**：选一把椅子 / 一个 emoji / 一张图，立即出结果卡（类型名 + 一句话 + 标签 + 盲区 + 可晒文案）。
- **行为范式**：气球风险（BART）、抛球（Cyberball）通过真实交互测行为倾向。
- **传播引擎**：每张结果卡都带「可晒文案」，利于社交分享与引流。
- **五维画像**：主动进取 / 独立思考 / 社交亲和 / 风险偏好 / 权威亲近。

## 本地预览

直接双击任意 `.html` 即可在浏览器打开；图片版需连同 `img/` 目录一起放置。
